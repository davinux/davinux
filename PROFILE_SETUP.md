## GitHub Actions

The repository includes a workflow (`.github/workflows/snake.yml`) that generates a snake animation of your contribution graph every 6 hours and pushes it to the `output` branch.

To enable:
1. Go to Settings > Pages
2. Set source to "Deploy from a branch"
3. Select `output` branch and `/` folder
4. Save

The snake animation will be available at: `https://github.com/davinux/davinux/blob/output/github-contribution-grid-snake.svg`
